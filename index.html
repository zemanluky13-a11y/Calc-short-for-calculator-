Full function library available via math.js — gcd, lcm, gamma, hyperbolic trig, complex numbers (2+3i), etc. Just type them.
Symbolic derivatives use math.js's algebraic engine. Integrals and limits are computed numerically to high precision (Simpson's rule / two-sided epsilon approach) — exact for smooth, well-behaved functions.
Examples: "100 kg" → "lb", "98.6 degF" → "degC", "60 mph" → "m/s", "2 hours" → "minutes".
